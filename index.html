02. AI OUTPUT STABILIZATION & AUTONOMOUS QA

CSS line-clampによる物理的な文字溢れ防止と、
Python標準libによる納品前自律テストで手戻りゼロを実現する

手戻りゼロの安全装置
SAFETY MECHANISM 01 物理ガード

CSS文字溢れ防止規約 (`line-clamp`)

AIが想定以上の長文を出力しても、
スライド枠（720px）を突き抜けない物理レイアウト制限を強制適用。

<div class="ai-content">
• 見出し (h2/h3): 最大2行制限
• 本文段落 (p): 最大6行制限
• 箇条書き (li): 最大3行制限
</div>
効果: 溢れたテキストは自動で三点リーダー化され崩壊ゼロ
SAFETY MECHANISM 02 自律修復ループ

Python品質テスト (`verify_slide.py`)

外部依存ゼロ（標準libのみ）。
AIが納品前にCLIで自動検証し、不備があれば自己修復してから提示。

$ python3 scripts/verify_slide.py deck.html
✓ スライド枚数とメタ枠の1:1一致検証
✓ 文字数上限ヒューリスティック (700字超過検知)
✓ 印刷用ゼロマージンCSS & 必須UI IDの整合性
➔ Exit Code 0 (全テスト合格時のみ納品)
安心: CLIのない環境での架空ログ捏造も厳禁化 (Anti-Hallucination)

03. DESIGN GOVERNANCE & ANTI-AI-SMELL

AI特有の空虚な3均等カードや抽象バズワードを排除し、
完全文のAction Titleと視覚的アンカーで会議での即時合意を引き出す

AI臭さを徹底排除
✕

やりがちなAIスライド（AI-Smell）

  • •
    無意味な3均等カード: どの案が重要か分からず目線が泳ぐ
  • •
    抽象バズワード連呼: 「相乗効果」「多面的展開」など具体性のない語句
  • •
    意味のない飾りアイコン: 文脈のないロケット・電球・握手
  • •
    名詞止めの見出し: 「〇〇について」「今後の展望」のみで結論不明
結果: 現場に響かず、社内での意思決定が停滞する
✓

AINativeSlide 行動規範（Anti-AI-Smell）

人間仕様
  • •
    視覚的アンカーの義務化: 推奨案や重要課題に幅拡張・色枠を設定
  • •
    具体的動作・数値へリライト: 「夜間バッチ同期」「工数60%減」等
  • •
    Action Title (40〜60字): 事実と示唆を動詞結びの完全文で明記
  • •
    社内向け6大構成パターン: 課題打ち手・比較・境界線・全体像・手順・FAQ
成果: 読むだけで次のアクションが決まる実践的な社内提案書になる
