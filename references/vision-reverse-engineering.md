# Vision リバースエンジニアリング手順書 (Vision Reverse Engineering)

スライドの参考画像（スクリーンショット、手書きラフ、既存プレゼン画像）が添付された際に、マルチモーダルAI（LLM）の画像推論能力を活用してHTML/Tailwindコードに高精度変換するための解析手順です。

---

## 1. アスペクト比の判定フロー

1. **画像のアスペクト比を測定**:
   - 横幅と高さの比率を推論する。
   - **比率がおよそ 1.7〜1.8（横長・ワイド）**: `16:9` を選択。
     - スライドサイズ: `1280px × 720px`
     - 印刷設定: `@page { size: 16in 9in; margin: 0; }`
   - **比率がおよそ 1.3〜1.4（正方形寄り・従来型）**: `4:3` を選択。
     - スライドサイズ: `1024px × 768px`
     - 印刷設定: `@page { size: 4in 3in; margin: 0; }`
   - 迷った場合・判別不能な場合は、モダンなプレゼンの標準である `16:9` を採用する。

---

## 2. カラーパレットの抽出とTailwindマッピング

画像の主要ピクセル群から以下の色相をサンプリングし、`tailwind.config` に落とし込みます。

1. **Primary Color (ブランド基調色)**:
   - 最も目立つ見出しや強調枠、アイコンに使われている色（例: コーポレートブルー、ネイビー、エメラルド等）
   - 例: `brand: { 500: '#2563eb', 600: '#1d4ed8', ... }`
2. **Accent Color (差し色)**:
   - バッジやピルタグ、重要な数値にピンポイントで使われている色（例: オレンジ、シアン、ゴールド等）
   - 例: `accent: { 500: '#f59e0b', ... }`
3. **Background & Surface (地色)**:
   - スライド全体の背景（オフホワイト `#f8fafc` や ダークネイビー `#0f172a`）
   - カードの背景（ピュアホワイト `#ffffff` や 半透明グラス `#ffffff/80`）
4. **Semantic Color (意味色)**:
   - ポジティブ・達成: グリーン系
   - ネガティブ・課題: レッド/ローズ系

---

## 3. レイアウト構造のリバースエンジニアリング

画像の視覚的ブロック構造をCSS Grid / Flexboxへ変換します。

| 画像内の視覚構造 | Tailwind 実装手法 |
| :--- | :--- |
| **左右に2つのブロックが並んでいる** | `grid grid-cols-2 gap-8` |
| **3つまたは4つのボックスが均等に並んでいる** | `grid grid-cols-3 gap-6` または `grid grid-cols-4 gap-4` |
| **ステップ番号（1, 2, 3）が横に流れている** | `flex items-center gap-4` または `grid grid-cols-3` + 矢印SVG |
| **大きな数字とその下に小さな解説文** | `text-4xl font-extrabold` + `text-xs text-slate-500` |
| **中央にメインの図、周りに吹き出し** | 相対配置カード または 2カラムの図解・解説スプリット |

---

## 4. テキストの抽出と構造化

- 画像内の文字情報（OCR的抽出）をそのままベタ書きするのではなく、
  - **大見出し**（主メッセージ）
  - **小見出し**（各要素のタイトル）
  - **箇条書き**（要点・補足）
  に階層化して整理し、インライン編集（`contenteditable`）しやすい形で埋め込みます。
