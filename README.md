## プロジェクトの思想とメリット

従来のPowerPoint作成における「フォント崩れ」「ライセンス制約」「共同編集のコンフリクト」「デザインの統一しにくさ」を解消するため、Web標準技術（HTML5 + Tailwind CSS CDN + Google Fonts）のみで動作するプレゼンテーション環境を構築しました。

- **Single-File 完全自己完結**: 外部ビルドツール（npm/webpack等）やサーバーは一切不要。ダブルクリックするだけでブラウザで開き、即座に編集・投影可能。
- **美しさと論理性の両立**: 洗練されたモダンデザイン美学（調和のとれたTailwindカラー、モダンタイポグラフィ、階層的カードコンポーネント）をプリセット。
- **AIとのシームレスな対話**: 各スライド下の指示欄と連携し、生成AI（ChatGPT, Claude, Gemini, Cursor等）にコメントをワンクリックで渡して反復修正（Iteration）が可能。

## 実装済み機能

### 1. 全画面プレゼンテーションモード（スライドショー）
ヘッダーの **「▶ 発表」** ボタン、またはキーボードの **`F`** キーを押すことで、プロジェクター投影用の全画面スライドショーが起動します。
- **自動アスペクト比フィット**: ディスプレイ解像度に関わらず、CSS `transform: scale()` により常に完全な比率（16:9 または 4:3）で画面中央に最大表示されます。
- **直感的なスライド送り**:
  - `→` / `↓` / `Space` / `PageDown` / 画面右側クリック: 次のスライド
  - `←` / `↑` / `PageUp` / 画面左側クリック: 前のスライド
- **レーザーポインター (`L` キー)**: マウスカーソルが赤く光るグロードットに切り替わり、注目箇所の指示が容易に行えます。
- **終了 (`Esc` キー)**: いつでもワンキーで通常の編集モードへ安全に復帰します。

### 2. スピーカーノート（発表メモ）
各スライド直下にタブ切り替え式のメタ情報コンテナが配置されています。
- **通常時（推敲・準備中）**:
  - スライド下の **「🎤 発表メモ」** タブをクリックすると、トークスクリプトや発表補足原稿を直接入力できます（`contenteditable="true"`）。
- **スライドショー投影中**:
  - **`N`** キーを押すと、画面下部に半透明のダークパネルで現在のスライドの発表原稿がポップアップ。手元で原稿を確認しながら発表できます。
- **PDF出力への配慮**:
  - `@media print` により、PDF保存時には発表メモは一切写り込みません。

### 3. スライド目次・一覧（TOCドロワーナビゲーション）
ヘッダー左側の **「☰ 目次」** ボタンをクリックすると、左サイドから滑らかなアニメーションでスライド一覧ドロワーが展開します。
- **見出し自動走査**: スライド内の `h1` や `h2` をスクリプトが自動認識し、スライド番号とタイトル一覧を動的に生成します。
- **ワンクリックジャンプ**: タイトルをクリックするだけで、該当スライドへスムーズにスクロール（スライドショー中はそのページへ即座に切り替え）。
- **現在地ハイライト**: 表示中のスライドが一覧上で自動的にアクティブ表示されます。

### 4. ブラウザ直接推敲 & インライン書式バー
- **直接編集**: スライド上のすべてのテキストをクリックしてそのままキーボードで編集可能。
- **選択時ミニ書式バー**: テキストを範囲選択すると、その直上にフローティング書式バーが自動出現。
  - **太字 (Bold)**
  - **部分文字サイズ変更**: 選択した語句のみ `[A-]` `[A+]` で縮小・拡大
  - **部分文字カラー変更**: 5色のブランドカラーを部分適用
  - **蛍光ペンハイライト**: 黄色・緑色のマーカー効果で重要キーワードを強調
  - **書式解除**: 選択部分のインラインスタイルを一発リセット

### 5. テーマカラー & 全体フォントサイズ動的スケーリング
- **テーマカラー一括切替**:
  - ヘッダーのカラーパレットから、5つの洗練されたプリセット（Indigo, Navy, Emerald, Amber, Rose）を選択可能。
  - 虹色アイコンのカスタムカラーピッカー（`<input type="color">`）から、企業ブランドカラーのHEXコードを全スライドに一瞬で適用可能。
- **全体文字サイズ調整**:
  - ヘッダーの `[A-]` `100%` `[A+]` コントローラーで、全スライドのフォントサイズを 85%〜125% の範囲で滑らかに一括調整。

### 6. スライドごとの修正指示（コメント）& AI反復修正連携
- 各スライド直下の **「💬 修正指示」** タブに、推敲中に気づいた修正点（「テキストの折り返しを解消」「箇条書きの要約」「KPI数値の変更」等）を入力。
- **「📋 指示をコピー」**: 入力された全スライドの指示を `【スライド X への修正指示】` の整形フォーマットでクリップボードへ一括コピー。AI（ChatGPT, Claude, Gemini, Cursor等）のプロンプト欄に貼り付けるだけで改訂版が依頼できます。
- **「📥 HTML保存」**: コメントや編集内容を含んだ最新のSingle-File HTMLファイルをダウンロード。

### 7. 抽象概念を示すAI生成画像（Concept Imagery）とD&D差し替え
- 抽象的なビジョンやシステム全体像を視覚化するため、画像生成AI用の専用プロンプト（文字崩れ防止仕様）を併出。
- スライド内の `.image-dropzone` にローカルの画像ファイルを **デスクトップから直接ドラッグ＆ドロップ** するだけで、即座に画像が差し替わります。

### 8. 厳格な比率制御（16:9 / 4:3）& 余白ゼロPDF印刷
- CSS `@page { size: 16in 9in; margin: 0; }` と `.slide { page-break-inside: avoid; }` の厳格な設計により、ブラウザの「印刷（PDFに保存）」で改ページずれゼロ・余白ゼロのピクセルパーフェクトなPDFを出力できます。

## キーボードショートカット一覧

| キー | 対象モード | 動作内容 |
| :--- | :--- | :--- |
| **`F`** / **`F5`** | 通常 / 投影 | 全画面プレゼンテーションモードの開始 / 終了 |
| **`Esc`** | 投影 / ドロワー | スライドショーの終了、または目次ドロワーを閉じる |
| **`→`** / **`↓`** / **`Space`** / **`PageDown`** | 投影 | 次のスライドへ進む |
| **`←`** / **`↑`** / **`PageUp`** | 投影 | 前のスライドへ戻る |
| **`N`** | 投影 | 発表メモパネルのトグル表示 |
| **`L`** | 投影 | レーザーポインターモードのトグル（赤色グロードット） |

※テキスト入力欄や `contenteditable` の編集にフォーカスしている間は、誤動作を防ぐためプレゼンテーションショートカットは無効化されます。

## 使い方ガイド（AIとの連携・作成手順）

1. **スライド依頼の送信**:
   - AI（ChatGPT, Claude, Gemini, 各種AIエージェント等）に作成したいプレゼンのテーマや構成案を伝えます。
2. **Grill（4大論点）への回答**:
   - AIから提示される「目的」「比率」「枚数」「AI画像要否」の4問に番号（例: `1-A, 2-A, 3-B, 4-B`）で回答します。
3. **HTMLファイルの保存**:
   - 出力された単一HTMLコードを `slide.html` として保存し、ChromeやEdge等のブラウザで開きます。
4. **ブラウザ上での推敲・調整**:
   - スライドのテキストを直接推敲し、ツールバーでカラーやフォントサイズを好みに変更します。
   - スライド下の「💬 修正指示」欄に改訂要望を入力し、ツールバーの「指示をコピー」でAIに貼り付けて再生成を依頼します。
5. **プレゼンテーション投影 & PDF出力**:
   - 発表本番は `F` キーで全画面スライドショーを起動し、`N` で発表メモを確認しながら登壇。
   - 配布用にはツールバーの「PDF保存」をクリックし、余白「なし」、背景グラフィックス「オン」で保存します。

## 🚀 今後の実装候補（ロードマップ）

PowerPointからの完全移行をさらに強固なものにするため、以下の機能拡張を今後の実装候補として計画しています。

### 候補 A: スライドマネージャーUI（並べ替え・複製・削除・追加）
- **概要**: スライド一覧をサムネイル形式またはカード形式で俯瞰し、スライドの順序を直感的に組み替える機能。
- **詳細仕様案**:
  - 目次ドロワー内に各スライドのドラッグハンドル（`draggable="true"`）を設け、上下ドラッグでスライド順序を即座に入れ替え。
  - 各スライド右上に「複製（Duplicate）」「削除（Delete）」ボタンを配置。
  - スライド間に「＋ スライド追加」ボタンを配置し、「表紙」「AS-IS/TO-BE」「3列カード」「ロードマップ」などの定型パターンを選んでワンクリック挿入。

### 候補 B: ビジネスチャート・グラフ描画（SVG / Chart.js）
- **概要**: 複雑な数値データや市場成長予測を、視覚的なビジネスチャートとして Single-File 内で描画する機能。
- **詳細仕様案**:
  - 軽量なインラインSVG生成スクリプト、またはCDN経由の `Chart.js` を統合。
  - 棒グラフ（Bar）、折れ線グラフ（Line）、円・ドーナツグラフ（Doughnut）、レーダーチャート（Radar）をサポート。
  - スライドのテーマカラー変数（`var(--brand-500)` 等）と連動し、テーマ変更時にグラフの配色も自動で再描画。
  - HTML内のシンプルな表（`<table>`）や `data-*` 属性を書き換えるだけでグラフが動的に更新されるデータバインディング。

### 候補 C: 表（テーブル）の直感編集サポート
- **概要**: 競合比較表や機能一覧表の行・列をブラウザ上で柔軟に増減・編集できる機能。
- **詳細仕様案**:
  - 表ホバー時に行末・列末に「＋」ボタンを表示し、1クリックで行追加・列追加が可能。
  - 各セルのテキスト配置（左寄せ・中央寄せ・右寄せ）や背景色強調（Coreプラン・推奨オプション等）のトグル機能。

### 候補 D: 企業ロゴ & 機密区分（CI/CD）の一括管理設定
- **概要**: 全スライドのヘッダー・フッターに共通して表示される企業ロゴやコンフィデンシャル表示を一括管理する設定パネル。
- **詳細仕様案**:
  - ヘッダーの設定モーダルから、企業ロゴ画像URLまたはSVGコードを一括指定。
  - 機密区分バッジの選択（`CONFIDENTIAL` / `社外秘` / `INTERNAL ONLY` / `PUBLIC`）を全スライドに一瞬で同期。

### 候補 E: ベクターアイコンライブラリの体系的インポート
- **概要**: テック系・ビジネス系スライドで多用されるアイコンを、コード編集なしで差し替えられるUI。
- **詳細仕様案**:
  - Feather Icons / Lucide Icons / Heroicons の主要SVGアイコンセットを内包。
  - アイコンをクリックするとポップアップピッカーが表示され、検索・選択でアイコンが即時切り替わる機能。

### 候補 F: プレゼンテーションタイマー & 経過時間表示
- **概要**: 登壇や役員報告時の持ち時間オーバーを防ぐためのプレゼンター支援機能。
- **詳細仕様案**:
  - スライドショー起動時に「発表予定時間（例: 15分）」を設定。
  - スライドショー画面下部（発表者コントロールバーまたはノートパネル内）に、経過時間と残り時間のプログレスバーを薄く表示。
  - 残り時間3分、1分で微小なビジュアルアラート（黄色・赤色のドット点滅）を通知。
